# Who can Contribute?
Generally speaking, anyone is welcome to attempt to contribute to this project if they would like so long as the follow the below rules.

## Consider Before Contributing
1. I'd prefer for this project to be human made. I may reject contributions I suspect to be made with AI for the purposes of preserving that.
2. Make sure your contribution is meaningful. I will reject contributions if they don't actually add any value to the repository.
3. If a contribution, you made turns out to be seriously problematic in some way you will be barred from any further contributions to this repository.

This obviously isn't a comprehensive list, but they are just my thoughts at the moment on how I will be generally considering contributions to this project.
Obviously, I may still reject contributions for any reason, but if you follow these guidelines then I probably won't have a problem with it.

Finally, the issues that are currently up are the main things that need addressing in the project so please reference those first before attempting to contribute to know what needs to be done. Do note that if an issue is currently assigned then you should likely not engage with it as the person assigned to it is likely in the process of handling it.
